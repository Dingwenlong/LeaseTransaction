# 校园个人物品租赁与交易系统 - 后台管理端

> 基于 Vue 3 + TypeScript + Vite 构建的校园物品租赁交易平台后台管理系统

## 项目概述

本项目是校园个人物品租赁与交易系统的后台管理端，为管理员提供用户管理、物品审核、订单监控、数据统计等核心功能。

### 选题背景

随着我国高等教育规模持续扩大，在校大学生群体已突破4700万人，形成了庞大的消费市场和闲置物品存量。现有解决方案存在信息不对称、跨校区交易成本高、缺乏身份认证导致的信任缺失等问题。本项目依托微信小程序的轻量特性和微信生态的社交关系链，构建基于校园身份认证的可信交易环境。

## 技术栈

| 技术 | 版本 | 说明 |
|------|------|------|
| Vue | 3.x | 前端框架 |

| Vite | 5.x | 构建工具 |
| TailwindCSS | 3.x | 样式框架 |
| Pinia | 2.x | 状态管理 |
| Axios | 1.x | HTTP 客户端 |

## 功能模块

### 1. 后台首页
- 关键数据概览
- 快捷功能入口
- 重点事项提醒

### 2. 用户管理
- 用户账号审核
- 权限分配管理
- 信用等级调整
- 违规行为处理

### 3. 物品审核
- 发布物品信息合规性审查
- 敏感内容过滤
- 分类纠错管理

### 4. 订单监控
- 全平台订单状态跟踪
- 异常订单预警
- 纠纷仲裁处理

### 5. 数据统计
- 用户活跃度报表
- 物品流转率分析
- 热门类别统计
- 财务收支汇总

### 6. 系统配置
- 轮播图管理
- 公告发布
- 分类字典维护
- 参数设置

## 项目依赖

```bash

npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 运行类型检查
npm run type-check

# 运行代码检查
npm run lint
```
